# 宠物 Rive 从零手把手指南（做 bear 母文件）

配合 `docs/pet-rive-spec.md`（契约/规格）使用。本文讲**具体怎么在 Rive 编辑器里，从你那张
成品图一步步做出会动的 `bear.riv`**。dog/cat 之后复制 bear 套皮即可（见规格 0.1）。

> 心理预期：第 3–6 步是动画师的手工活。**如果你没用过 Rive，先花 1–2 小时做完官方入门教程
> （rive.app → Learn / Get Started，或官方 YouTube 的 "Rive 101"），再回来照本文做**，会顺很多。
> 你的优势：形象已定，跳过了最难的创意环节。

---

## 0. 前置

- 一台能开浏览器的电脑（Rive 编辑器是网页版）。
- 你那张宠物**完整正面成品图**（PNG/JPG）。
- 打开 `pet-rive-spec.md` 放旁边——命名、情绪编号、尺寸都以它为准。

---

## A. 注册 + 新建文件 + 设画板

1. 打开 **rive.app** → 注册登录 → 进 **Editor**，新建一个 File。
2. 进去后注意左上角有 **Design / Animate** 模式切换，现在停在 **Design**。
3. 选中画板（Artboard），在右侧 Inspector 把尺寸设成**正方形**，如 `1000 × 1000`。
4. 背景**保持透明**（不要给画板加不透明底色矩形）。

## B. 导入参考图当描摹底图

1. 直接把你的成品图**拖进画板**——它会变成一个 image 资源。
2. 调整大小让它居中、四周留约 10% 边距。
3. 在 Hierarchy（左侧层级树）里把它的不透明度调到 ~30%、**锁定**这一层——只当描摹参考，最后删掉。

## C. Design 模式：逐部位描成矢量（最花功夫的一步）

核心原则（来自规格第 7 节）：**每个部位画成「完整的闭合形状」，遮挡靠图层前后顺序解决，不要只描露出来的部分。**

1. 用 **Pen 工具**（钢笔）沿参考图描每个部位的轮廓，闭合成形；规则形状可用 Ellipse/Rectangle 工具起形再调。
2. 一次只描一个部位，描完在 Hierarchy 里**建组并命名**（见规格第 7 节清单）：
   `head`(含脖根) / `ear_L` / `ear_R` / `eye_L` / `eye_R` / `brow_*` / `muzzle` /
   `torso` / `arm_L`(含肩) / `arm_R` / `leg_L`(含胯) / `leg_R` / `tail`。
3. **画完整**：身体画整块、胳膊画到含肩、头画到含脖根——这样旋转关节时底下不露缝。
4. **配色**：在 Inspector 的 Fill 里填颜色；想精确还原原图就用十六进制色值。保持**纯色平涂**，少用渐变。
5. **排前后顺序**（z 序＝Hierarchy 里的上下）：身体在最底 → 四肢 → 头 → 五官在最上。
6. **设每个部位的 Origin（旋转中心/轴点）**：选中组，把它的 origin 手柄挪到该关节处
   （胳膊的 origin 放肩、头的放脖子）——这样之后旋转才自然。
7. 全部描完后，**隐藏/删掉参考底图**，看纯矢量版是否完整好看；缩到 ~32px 预览确认小尺寸认得出。

## D. 绑骨骼（让部位能动）

1. 用 **Bone 工具**搭一套骨架：盆骨/脊柱为根，往上接头、往两侧接手臂、往下接腿、尾巴一根。
2. 把各部位**绑到骨头**：
   - 简单做法（cut-out）：在 Hierarchy 里把部位组**挂到对应骨头下**（组跟着骨头走）。
   - 想要弯曲自然：给该形状加 **Mesh**，把网格顶点 **Bind** 到一根或多根骨头（蒙皮）。
3. 在 Design 里**手动转转骨头测试**：胳膊绕肩转、头绕脖转，确认不露缝、不穿帮。
4. **规划通用骨架**：骨头数量与命名按「以后要套狗和猫」来定（规格 0.1），别做只有熊才有的特殊骨。

## E. Animate 模式：做 9 个情绪时间线

切到右上角 **Animate** 模式。

1. 在 Animations 列表点 **+** 新建动画，**命名要能对上规格第 3 节**（建议直接叫 `happy / waiting / sad / celebrate / sleepy / anxious / expecting / surprised / clingy`）。
2. 做动画＝在时间轴上**给骨头/组的 旋转/位移/缩放 打关键帧**。例：`happy` ＝ 轻微呼吸 + 偶尔眨眼，**设为 Loop 循环**。
3. **顺序建议**：先把 `happy`(0) 和 `waiting`(1) 做扎实，其余 7 个在此基础上改幅度/表情**派生**，省力。
4. 每个动画都做成**可无限循环的待机动作**（不是播一次就停）。
5. 单独做一个 **`tap`** 动画：300–500ms 的挤压回弹/眨眼/冒爱心，**一次性**（不循环），用于拍一拍。

## F. 状态机：把情绪和拍一拍接上代码契约

仍在 Animate 模式。

1. 在列表里 **+** 新建 **State Machine**，名字**保持默认 `State Machine 1`**（规格第 1 节，必须逐字一致）。
2. 在 Inputs 面板 **+** 加两个输入（名字大小写必须一致）：
   - `emotion` → **Number**，默认值 **0**
   - `tap` → **Trigger**
3. 把 9 个情绪动画**拖进状态机画布**变成 9 个 State。把 **Entry（入口）箭头**连到 `happy`。
4. 连**过渡（Transition）**：从 `Any State` 分别连到每个情绪 State，给每条过渡加条件
   `emotion == N`（happy=0, waiting=1, sad=2, celebrate=3, sleepy=4, anxious=5, expecting=6, surprised=7, clingy=8）。过渡时间给 0.1–0.2s 平滑。
5. **tap 单独一层（Layer）**：新建一个 Layer 放 `tap` 动画，进入条件＝Trigger `tap`，
   播完经 Exit 回去——这样拍一拍叠在情绪之上，不打断情绪循环。

## G. 编辑器内自测（不写代码就能验）

1. 进状态机的 **Preview/播放**，手动把 `emotion` 从 0 改到 8，看是否切到对应的 9 个情绪。
2. 点一下 `tap` Trigger，看是否播放一次拍拍反应并回到当前情绪。
3. 对照规格第 8 节自检清单逐条打勾。

## H. 导出 `.riv`

1. 菜单里找 **Export / Download for runtime**，导出**运行时 `.riv`**（不是分享链接、不是 `.rev` 源文件）。
2. 文件命名 `pet.riv`。

## I. 交给工程 / 之后的 dog、cat

- 把 `pet.riv` 发给开发，或直接放 `assets/pets/bear/pet.riv`；开发把 `rive-assets.ts` 里 bear 那行
  `null` 改成 `require(...)`，重建原生 dev client 即生效（规格第 9 节）。
- **dog / cat**：复制 bear 这个 Rive 文件，**骨架/状态机/动画全留**，只把挂在骨头上的矢量换成
  狗/猫的部件（reskin），导出 `dog/pet.riv`、`cat/pet.riv`。九情绪动画**不用重做**。

## 卡住时的求助清单

- 描矢量描不准 → 可先用 vectorizer.ai / Illustrator Image Trace 把原图转 SVG，导进 Rive 再拆分修整。
- 不想自己学 Rive → 把 `pet-rive-spec.md` 整份甩给会 Rive 的动画师，就是完整需求单。
- 任一步卡住 → 在编辑器里截个图，回来问，逐步过。

## 学习资源

- Rive 官方 Learn / Get Started（rive.app 内）、官方文档、官方 YouTube 频道的入门与「骨骼/状态机」教程。
- 重点先看三块：**Vector drawing**、**Bones & Mesh（绑骨蒙皮）**、**State Machine（状态机 + Inputs）**。
